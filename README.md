# Hive RK Enterprise

A modern web application for **Hive RK Enterprise** based in Asansol, West Bengal.

The application showcases the enterprise's three primary business ventures:
1. **Hive The Lounge RK** — Premium café, live music, and hookah atmosphere near Galaxy Mall.
2. **Hive The Lounge RK 2.0** — 24-hour dining and ambient greenery on Shakespeare Sarani.
3. **Hive RK Enterprise Automobiles** — Quality inspected pre-owned motorcycles & scooters showroom.

---

## Design System

- **Primary Colors**: Charcoal (`#242424`), Pure White (`#FFFFFF`), and Electric Lime (`#C6FF35`).
- **Typography**: Modern geometric sans-serif **Manrope** (Headings) and **Inter** (UI, body, and metadata).
- **Interactive Features**:
  - Interactive 3D mouse parallax tilt showcase featuring the founder cutout and motorcycles.
  - 4-slide showcase switcher with seamless transitions.
  - 3D curved cards venture carousel with detailed modal views.
  - Real-time customer review ticker featuring verified Google and Justdial excerpts.
  - Fully responsive from mobile devices to ultra-wide desktop monitors.

## Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
